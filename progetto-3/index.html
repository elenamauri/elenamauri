Gyma — Workout Tracker

I designed and built Gyma, a personal workout tracker that turns complex training data into a calm, session-first experience. From live logging and rest timers to progression, history, and cloud sync, the product reduces friction in the gym while keeping every set measurable and meaningful.

The Challenge

Logging under load

Most workout apps either drown users in features or break the flow mid-set. Between sweaty hands, short rest windows, and the need to compare previous loads, logging becomes a second workout. The objective was to design a tool that stays out of the way during the session, then becomes precise and insightful the moment the workout ends.

The Approach

Session-first product thinking

I structured the experience around the live session: previous set as default, one-tap completion, rest timer as a horizontal countdown, and a persistent bar that keeps the workout reachable from anywhere in the app. Everything else — programs, catalog, progress — supports that core loop instead of competing with it.

A chalk-and-ink visual system

The interface uses a restrained palette — chalk, ink, and a single accent red — with condensed display type for hierarchy and mono details for measurable data. The result feels athletic without looking like a generic fitness template: calm enough for long sessions, sharp enough to read under gym lighting.

Role

My Role & Deliverables

End-to-end ownership: I defined the product, designed the experience, and built the working app as a solo side project.

  • UX & Information Architecture: Mapped the session-first journey across home, programs, live logging, history, and progress.
  • Visual & UI Design: Created a minimal mobile-first interface with a coherent chalk/ink/accent system.
  • Product Build: Implemented the PWA in Next.js, TypeScript, and Tailwind, with local-first storage and optional cloud sync.
  • Data Experience: Designed PR detection, weekly goals, progression rules, and session comparison to make training history actionable.

Outcome

A complete training companion

Gyma is a working product, not a concept deck. The main achievements include:

  • Low-friction logging: Previous loads and one-tap sets keep attention on the lift, not the UI.
  • Measurable progress: Volume, max load, streak, and compare views turn raw sets into a clear narrative.
  • Durable data: Local-first cache plus optional cloud account so training history survives device resets.
  • Design coherence: A single visual language across dashboard, session, and analytics reinforces trust and speed.
